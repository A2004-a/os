## 1. Goal
1. **Userspace Threads:** Implement Ring 3 multi-threading via `SYS_THREAD_CREATE` (clone-style thread spawning) sharing caller process virtual address space (`CR3`) and file table with isolated user stack, entry point argument passing, and thread-local storage (`SYS_SET_FS_BASE` / `wrfsbase`). Implement thread termination and cleanup via `SYS_THREAD_EXIT`.
2. **Futex Syscall (`SYS_FUTEX`):** Implement Fast Userspace Mutex primitive supporting `FUTEX_WAIT`, `FUTEX_WAKE`, and `FUTEX_REQUEUE` operations backed by hash-bucketed kernel wait-queues keyed by user virtual address and PID, guaranteeing race-free synchronization for userland pthreads/mutexes.
3. **Dynamic Linking & ELF Shared Object Loader:** Provide native ELF64 dynamic library (`ET_DYN`) loading, `PT_DYNAMIC` segment inspection (`DT_STRTAB`, `DT_SYMTAB`, `DT_NEEDED`, `DT_RELA`), relocation processing (`R_X86_64_RELATIVE`, `R_X86_64_GLOB_DAT`, `R_X86_64_JUMP_SLOT`), and dynamic symbol lookup (`sys_dlopen`, `sys_dlsym`).

---

## 2. Non-Goals
- Full glibc runtime compatibility (M12 focuses on musl-compatible ELF64 dynamic relocations for M13).
- Lazy symbol binding via Ring 0 PLT trampolines (relocations are resolved eagerly or through userland dynamic linker stubs).
- Asynchronous thread cancellation signals (`pthread_cancel`).
