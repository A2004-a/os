## 1. Goal
1. **Busybox-Style Coreutils Subsystem (`coreutils`):** Implement a high-performance multi-call utility engine providing 20+ core Unix/POSIX commands (`cat`, `echo`, `ls`, `mkdir`, `rm`, `touch`, `cp`, `mv`, `head`, `tail`, `wc`, `grep`, `pwd`, `uname`, `whoami`, `ps`, `kill`, `df`, `free`, `sleep`, `true`, `false`) integrated with M13 anonymous pipes and standard file descriptors.
2. **MicroPython Embedded Scripting Engine (`micropython`):** Implement a `#![no_std]` compliant lightweight Python interpreter capable of executing arithmetic, string manipulation, variable assignments, loops, conditional branches, and built-in functions in an isolated execution sandbox.
3. **WebAssembly (WASM) Sandboxed Runtime Engine (`wasm_runtime`):** Implement a high-safety WebAssembly MVP runtime (`wasmi`-compatible architecture) featuring binary format decoding (`\0asm` version 1), section validation, 64 KiB linear memory bounds isolation, stack machine opcode execution (`i32.const`, `i32.add`, `i32.sub`, `i32.mul`, `local.get`, `local.set`, `call`), gas/step metering, and zero-leak memory trapping.
4. **Milestone M14 Verification Suite:** Provide 16 certified automated test gates validating coreutils streaming, MicroPython script execution, and WASM sandboxed execution in QEMU hardware emulation.

---

## 2. Non-Goals
- Porting the full GNU coreutils suite (GNU sed, awk, find, coreutils > 100 binaries) — Busybox-style compact multi-call toolset covers necessary functionality.
- Complex Python C-extensions or external standard library modules (e.g. `numpy`, `ctypes`, `socket` module).
- WebAssembly SIMD, multi-threading (`shared-memory`), or WASI preview 2 (MVP core runtime with memory isolation is the focus).

## 8. Security Checks (CONTRACT.md Section 13A)
- WASM linear memory accesses strictly checked against `memory_size` to prevent out-of-bounds read/write.
- WASM execution instruction limit (gas/fuel counter) to prevent runaway infinite loops and CPU starvation.
- MicroPython interpreter memory consumption bounded to prevent kernel heap exhaustion.
- Coreutils file path inputs sanitized through `normalize_path` to prevent path traversal attacks.
