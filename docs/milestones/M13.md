## 1. Goal
1. **POSIX File Subsystem (`posix_files`):** Implement anonymous unidirectional pipes (`SYS_PIPE`), file descriptor cloning (`SYS_DUP`, `SYS_DUP2`), seek operations (`SYS_LSEEK`), and standard POSIX metadata inspection (`SYS_STAT`, `SYS_FSTAT`).
2. **POSIX Process & Identity Subsystem (`posix_process`):** Implement process cloning (`SYS_FORK`), process status harvesting (`SYS_WAITPID`), and standard POSIX credential queries (`getpid`, `getppid`, `getuid`, `geteuid`).
3. **POSIX Time & Clocks Subsystem (`posix_time`):** Implement high-resolution clock retrieval (`SYS_CLOCK_GETTIME` with `CLOCK_REALTIME` and `CLOCK_MONOTONIC`) and nanosecond-granularity sleep (`SYS_NANOSLEEP`).
4. **POSIX Sockets & Networking (`posix_sockets`):** Provide unified BSD socket interface mapping `socket`, `bind`, `connect`, `listen`, `accept`, `send`, `recv` to kernel VirtIO-Net stack.
5. **POSIX Threads (`posix_threads`):** Implement `pthread` synchronization and threading emulation atop M12 `SYS_THREAD_CREATE` and `SYS_FUTEX`.
6. **musl libc ABI Translation Layer:** Provide x86_64 Linux/musl system call translation table mapping standard musl syscall numbers into native NovaOS kernel handlers.

---

## 2. Non-Goals
- Full POSIX.1-2024 compliance across all 1,200+ POSIX APIs (M13 covers core files, processes, pipes, sockets, threads, and time required for coreutils and MicroPython).
- Asynchronous I/O (`aio_read`, `aio_write`).
- POSIX message queues (`mq_*`) — native NovaOS IPC mailboxes are used.

## 4. Adoption Check (Current Codebase Audit)
- **POSIX Files & Pipes:** `PARTIAL`. Basic file read/write/open/close exists in VFS, but anonymous pipes (`SYS_PIPE`), `dup/dup2`, and `lseek` are missing.
- **POSIX Processes:** `PARTIAL`. Process spawning (`SYS_SPAWN`) and child waiting (`SYS_WAIT`) exist, but POSIX `fork`, `waitpid`, and credential inspection are missing.
- **POSIX Time:** `PARTIAL`. `SYS_GET_TIME` exists (milliseconds), but POSIX `clock_gettime` (timespec with nanoseconds) and `nanosleep` are missing.
- **POSIX Sockets:** `EXISTS untested`. Sockets exist in `kernel/src/network/socket.rs` and syscalls 23–28; requires POSIX standardization.
- **musl libc ABI Translation:** `MISSING`. No translation table exists mapping Linux x86_64 syscall numbers to NovaOS gates.

## 8. Security Checks (CONTRACT.md Section 13A)

- Pipe buffer sizes strictly clamped to 4096 bytes per pipe to prevent kernel heap exhaustion.
- Privileged operations (changing UID/GID) guarded by capability checks.
